# Estoque Infraspeak PWA

PWA independente, de tela única, para acesso rápido ao estoque oficial do Infraspeak.

## Acesso
https://new.infraspeak.com/stock/warehouses

## Escopo
- Tela inicial responsiva inspirada na linguagem visual do Infraspeak.
- Acesso externo; nenhuma coleta de login ou senha.
- Instalação PWA onde o navegador suportar.
- Cache limitado a arquivos locais; requisições externas não são interceptadas.

## Hospedagem
Projeto estático, sem build: conectar o repositório à Vercel e usar o diretório raiz como publicação.

> Projeto independente, não oficial e não afiliado ao Infraspeak. A disponibilidade do destino depende do serviço externo.
